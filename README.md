# 🚀 Agendify - SaaS de Gestão e Agendamentos

O **Agendify** é uma aplicação web desenvolvida sob medida para otimizar o fluxo de atendimento, agendamentos e gestão de clientes para pequenas e médias empresas do comércio local (como barbearias, salões, clínicas e prestadores de serviços). 

Criado com foco em performance, design limpo e experiência de utilizador fluida, este sistema elimina planilhas manuais e processos lentos, trazendo automação e controlo total na palma da mão.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando uma stack moderna e robusta:

* **Backend:** Python, Flask, Flask-SQLAlchemy
* **Base de Dados:** SQLite (com suporte a migrações e escalabilidade)
* **Frontend / UI:** HTML5, CSS3, Jinja2 Templates, Bootstrap 5 / TailwindCSS
* **Controlo de Versões:** Git & GitHub

---

## ✨ Funcionalidades Principais

* **Painel de Controlo (Dashboard):** Visão geral e acesso rápido aos módulos principais do negócio[cite: 6].
* **Gestão de Clientes:** Registo, consulta e histórico de clientes de forma simples e intuitiva[cite: 6].
* **Gestão de Serviços:** Configuração de serviços oferecidos, preços e respetivas durações[cite: 6].
* **Módulo de Agendamentos:** Controlo de agenda, marcações e estados de atendimento em tempo real[cite: 6].
* **Autenticação Segura:** Sistema de login e registo protegido para utilizadores e administradores.
